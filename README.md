# 🌐 TSSR-P3 – Projet Infrastructure Réseau ÉcoTech

Projet réalisé dans le cadre de la formation **TSSR (Technicien Supérieur Systèmes et Réseaux)** à la **Wild Code School**, en collaboration avec l'équipe **EcoTech Solutions**.

---

## 🎯 Objectif pédagogique

Concevoir, documenter et déployer une **infrastructure réseau complète** pour une PME fictive, en tenant compte des contraintes environnementales, budgétaires et techniques.

---

## 🏗️ Description du projet

- Analyse des besoins réseau d’une entreprise (postes, services, accès internet)
- Conception d’un schéma réseau (LAN, Wi-Fi, DMZ si besoin)
- Choix des équipements (switchs, routeur, baie, brassage)
- Plan d’adressage IP, VLAN, sécurité (pare-feu, segmentation)
- Simulation ou déploiement sur VirtualBox / GNS3

---

## 🧰 Technologies & ressources

| Domaine          | Éléments utilisés                   |
|------------------|--------------------------------------|
| Conception réseau | GNS3, Lucidchart, topologie manuelle |
| IP & VLAN        | Adressage IPv4 statique, segmentation |
| Systèmes         | Windows Server, Linux (si utilisé)   |
| Outils            | Wireshark, VirtualBox, Excel         |
| Docs              | PowerPoint, PDF, schémas             |

---

## 👤 Mon rôle dans le projet (GRD78)

- Participation à la **topologie du réseau** (plan de câblage, IP)
- Élaboration du **plan d’adressage IPv4**
- Co-rédaction de la **documentation technique**
- Présentation orale du projet en groupe
- Réflexion sur la **sécurité réseau & durabilité**

---

Projet évalué en fin de bloc de formation, visant à mettre en œuvre une **infrastructure réaliste** pour une structure professionnelle, avec une approche écoresponsable.
